# Загрузчик Яндекс Диска

CLI на Go 1.25+ без внешних зависимостей. Скачивает все файлы личного
Яндекс Диска через REST API, сохраняя структуру каталогов.

## Запуск (PowerShell)

Получите OAuth-токен с доступом на чтение Диска по
[инструкции Яндекса](https://yandex.ru/dev/disk/rest/).

```powershell
$env:YANDEX_DISK_TOKEN = 'ваш-OAuth-токен'
go run . -dest 'D:\YandexBackup' -workers 8
```

Сборка и проверка:

```powershell
go test ./...
go vet ./...
go build -o yd-downloader.exe .
.\yd-downloader.exe -dest 'D:\YandexBackup' -workers 4 -attempts 5 -timeout 30m
```

Токен передаётся только API; ссылки скачивания и токен не выводятся в журнал.
Число goroutine загрузки задаётся `-workers` (по умолчанию 4).
Список файлов читается постранично, очередь ограничена числом workers.
При временных ошибках запросы повторяются с экспоненциальной задержкой;
учитывается Retry-After. `-timeout` ограничивает одну попытку загрузки файла.
Ctrl+C отменяет запросы; при ошибках программа возвращает код 1.

При завершении загрузчик сохраняет список файлов, которые не удалось скачать,
в `.yd-downloader-retry.json` в каталоге `-dest`. После полного обхода Диска
следующий запуск с тем же каталогом обрабатывает только этот список. Успешно
скачанные файлы исчезают из списка. Если список пуст, запуск завершается сразу.
После прерванного обхода следующий запуск снова читает список с Диска.
Чтобы заново проверить весь Диск, удалите `.yd-downloader-retry.json`.

Существующие файлы пропускаются только при совпадении размера и SHA-256.
Остальные заменяются после полной загрузки и проверки во временном файле.
Если API не отдаёт SHA-256, проверяется размер. Докачки с середины нет.
Неудачная загрузка сохраняет прежнюю версию файла. При обычном завершении
временные файлы удаляются; после принудительного убийства процесса могут
остаться `.yd-*.part`.

Пустые папки, корзина и чужие публичные ссылки не скачиваются.
На время копирования желательно не менять содержимое Диска: API не
предоставляет снимок списка файлов. Имена должны быть допустимы в локальной
файловой системе; учитывайте ограничения Windows и регистронезависимость
имён. Каталог назначения рекомендуется выделить специально под копию Диска.
Локальные файлы, отсутствующие на Диске, не удаляются.

Используются `GET /v1/disk/resources/files` и
`GET /v1/disk/resources/download`.
