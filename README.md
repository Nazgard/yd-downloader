# yd-downloader

Консольный загрузчик для резервного копирования личного Яндекс Диска. Сохраняет структуру каталогов, скачивает файлы параллельно и после полного обхода Диска повторяет только неудачные загрузки.

## Быстрый старт

Понадобятся Git, Go 1.25 или новее и OAuth-токен с доступом на чтение Диска. [Документация Яндекс Диска](https://yandex.ru/dev/disk/rest/)

В PowerShell выполните следующие команды и подставьте свой токен.

~~~powershell
git clone https://github.com/Nazgard/yd-downloader.git
cd yd-downloader

$env:YANDEX_DISK_TOKEN = 'ваш-OAuth-токен'
go run . -dest 'D:\YandexBackup'
~~~

Для запуска через отдельный файл соберите программу.

~~~powershell
go build -o yd-downloader.exe .
.\yd-downloader.exe -dest 'D:\YandexBackup'
~~~

## Параметры

| Флаг | По умолчанию | Назначение |
| --- | --- | --- |
| `-dest` | `downloads` | Каталог назначения. Относительный путь отсчитывается от текущего рабочего каталога. |
| `-workers` | `4` | Число параллельных загрузок. |
| `-attempts` | `5` | Максимальное число попыток. |
| `-timeout` | `30m` | Таймаут одной попытки загрузки файла. |

## Повторная загрузка

При завершении загрузчик записывает файлы с ошибками в `.yd-downloader-retry.json` внутри каталога назначения. После полного обхода Диска запустите ту же команду с тем же `-dest`. Программа обработает только сохранённый список и уберёт из него успешно скачанные файлы. При пустом списке запуск завершится сразу.

Если первый обход прервался, следующий запуск снова запросит список файлов с Диска. Чтобы начать новый полный обход, например для копирования новых файлов, удалите `.yd-downloader-retry.json`.

## Проверка файлов

Во время полного обхода существующий файл пропускается при совпадении размера и SHA-256. Новый файл сначала записывается во временный файл. Загрузчик проверяет размер и, если API вернул SHA-256, контрольную сумму. При ошибке прежняя версия сохраняется.

При временных ошибках запросы повторяются с экспоненциальной задержкой и учётом `Retry-After`. `Ctrl+C` отменяет запросы. При ошибках программа возвращает код `1`. После принудительного завершения процесса могут остаться временные файлы `.yd-*.part`.

Загрузчик копирует файлы личного Диска и сохраняет локальные файлы, отсутствующие на Диске. Пустые папки, корзина, чужие публичные ссылки и докачка с середины файла не поддерживаются. На время полного обхода желательно приостановить изменения на Диске, поскольку API возвращает список постранично.
